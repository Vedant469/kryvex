# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Kryvex, please report it privately rather than opening a public issue.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- Potential impact
- Any suggested mitigation

## Sensitive Information

Never commit:

- API keys
- AWS credentials
- Private keys
- Wallet seed phrases
- `.env` files
- Personal biometric data

Use `.env.example` for configuration documentation.
